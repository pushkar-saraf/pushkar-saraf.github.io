Where to set up a table

  1. Free, apply
    Grand Lake free speech table

    The market keeps a card table for community groups. Applications reopen Jan 1, 2027.

    Details
  2. Ask
    Temescal and Old Oakland markets

    Urban Village runs both. Ask about a community table through their contact page.

    Details
  3. Free room
    Oakland Public Library rooms

    Rooms at the Main Library and 10 branches are free for free, public events with no sales. Apply 2 weeks to 90 days ahead.

    Details
  4. Plan ahead
    Library program proposals

    Pitch a breathing workshop as a library program, 3 to 6 months ahead.

    Details
  5. Paid
    Oakland First Fridays

    Nonprofit booths start around $150 on Telegraph Ave.

    Details
  6. Next season
    Freedom Farmers' Market

    Second and fourth Saturdays, July to November, at 4521 Telegraph Ave. The 2026 season has ended, so ask about a table next summer.

A volunteer guide. Oakland law bans flyers on poles, trees, meters, signs, sidewalks and parked cars, so use windows and boards with the owner's okay.
